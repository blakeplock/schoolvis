HOW TO READ THE REPORT

Measurement, not magic.

What is measured

Presence of tracked school names in a fixed set of parent-intent answers, separated by platform and topic. Counts are normalized against the number of responses actually captured.

What is not measured

Real-world parent usage, search ranking, admissions conversion, market share, or the quality of education. Scores from different collection methods must not be combined without disclosure.

What comes next

An optional local five-question OpenAI API audit is available. Repeat sampling, independent citation verification, and cross-platform reliability estimates are not yet implemented.
