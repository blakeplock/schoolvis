# Contributing to SchoolVis

We welcome reproducible improvements under Apache-2.0. Read `AGENTS.md`, `SECURITY.md`, `docs/METHODOLOGY.md`, and `docs/DEPENDENCIES.md` first.

Before a pull request: run `npm ci --ignore-scripts`, `npm run check`, and attempt `npm audit --audit-level=high` when network access is available. Report all results (including failures or unavailable checks). Explain any measurement, licensing, privacy, or security impact. Do not add non-MIT/non-Apache dependencies or unverified AI-provider results. Please include test coverage for changed behavior.

For security defects, follow the private disclosure procedure in `SECURITY.md` rather than opening a public issue.
